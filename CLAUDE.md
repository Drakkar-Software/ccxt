# CCXT Exchange Implementation Guide

This is the Drakkar-Software fork of CCXT — a transpiled, unified multi-crypto-exchange library.

## Architecture Overview

CCXT follows a **TypeScript-first** architecture. Exchange code is written ONLY in TypeScript (`ts/src/`), then automatically transpiled to Python, PHP, Go, and C#. **Never write exchange code directly in Python, PHP, Go, or C#.**

## Repository Structure

```
ts/src/{exchange}.ts           ← PRIMARY SOURCE (only file you edit)
ts/src/abstract/{exchange}.ts  ← AUTO-GENERATED from describe().api
ts/src/base/Exchange.ts        ← Base class (408KB, all safe* methods)
ts/src/base/errors.ts          ← Error class hierarchy
ts/src/base/types.ts           ← Type definitions (Dict, Str, Num, Market, Order, Ticker, etc.)
ts/ccxt.ts                     ← Exchange registry (auto-updated by export-exchanges)
python/ccxt/{exchange}.py      ← TRANSPILED OUTPUT (do not edit)
python/ccxt/abstract/{exchange}.py
python/ccxt/async_support/{exchange}.py
php/{exchange}.php             ← TRANSPILED OUTPUT (do not edit)
php/abstract/{exchange}.php
php/async/{exchange}.php
cs/ccxt/                       ← TRANSPILED OUTPUT
go/v4/                         ← TRANSPILED OUTPUT
examples/ts/                   ← TypeScript examples
examples/py/                   ← Python examples
build/transpile.ts             ← Main transpiler (147KB)
build/generateImplicitAPI.ts   ← Abstract class generator
build/export-exchanges.js      ← Exchange registry updater
```

## Adding a New Exchange — Step by Step

### 1. Create the TypeScript Source

Create `ts/src/{exchange}.ts` with this structure:

```typescript
import Exchange from './abstract/{exchange}.js';
import { ExchangeError, BadRequest, ArgumentsRequired } from './base/errors.js';
import { TICK_SIZE } from './base/functions/number.js';
import type { Market, Str, Dict, Ticker, Num, Currencies, int, Order, OrderType, OrderSide } from './base/types.js';

export default class myexchange extends Exchange {
    describe (): any {
        return this.deepExtend (super.describe (), {
            'id': 'myexchange',
            'name': 'MyExchange',
            'countries': ['US'],
            'rateLimit': 1000,
            'version': 'v1',
            'certified': false,
            'pro': false,
            'has': { /* feature flags */ },
            'urls': { 'logo': '...', 'api': { 'rest': '...' }, 'www': '...', 'doc': ['...'] },
            'api': {
                'public': {
                    'get': ['endpoint1', 'endpoint2/{id}'],
                    'post': ['endpoint3'],
                },
                'private': {
                    'get': ['private-endpoint'],
                    'post': ['private-endpoint2'],
                },
            },
            'fees': { ... },
            'precisionMode': TICK_SIZE,
            'requiredCredentials': { 'apiKey': false, 'secret': false },
            'features': { ... },
            'options': { ... },
        });
    }

    // Implement methods: fetchCurrencies, fetchMarkets, fetchTicker, createOrder, etc.
    // Implement parsers: parseTicker, parseOrder, parseOrderStatus, etc.
    // Implement sign() for request signing
    // Implement handleErrors() for error parsing
}
```

### 2. Create the Abstract Class

Create `ts/src/abstract/{exchange}.ts`. This defines implicit API methods auto-generated from `describe().api`:

```typescript
// PLEASE DO NOT EDIT THIS FILE, IT IS GENERATED AND WILL BE OVERWRITTEN
import { implicitReturnType } from '../base/types.js';
import { Exchange as _Exchange } from '../base/Exchange.js';

interface Exchange {
    publicGetEndpoint1 (params?: {}): Promise<implicitReturnType>;
    publicGetEndpoint2Id (params?: {}): Promise<implicitReturnType>;
    publicPostEndpoint3 (params?: {}): Promise<implicitReturnType>;
    privateGetPrivateEndpoint (params?: {}): Promise<implicitReturnType>;
    privatePostPrivateEndpoint2 (params?: {}): Promise<implicitReturnType>;
}
abstract class Exchange extends _Exchange {}
export default Exchange
```

**Method naming convention:** `{accessLevel}{HttpMethod}{EndpointPath}` in camelCase.
- `public` + `GET` + `currencies` → `publicGetCurrencies`
- `public` + `GET` + `exchange/{id}` → `publicGetExchangeId`
- `private` + `POST` + `order/create` → `privatePostOrderCreate`

### 3. Register in ts/ccxt.ts

Add three entries (alphabetically ordered):

```typescript
// Import (between whitebit and woo for example)
import myexchange from './src/myexchange.js'

// Exchanges object
'myexchange': myexchange,

// Export block
myexchange,
```

### 4. Build and Transpile

```bash
# Full pipeline (recommended)
npm run export-exchanges    # Updates ts/ccxt.ts, __init__.py, Exchange.php registrations
npm run emitAPI myexchange  # Generates abstract classes for all languages
npm run tsBuild             # Compiles TypeScript to JavaScript
npm run transpileRest myexchange  # Transpiles to Python/PHP (pass exchange name for single)

# Or use the combined pipelines:
npm run pre-transpile       # export-exchanges + tsBuild + emitAPI + validation
npm run transpile           # transpileRest + transpileWs (all exchanges)
npm run build               # Full build pipeline
```

**Important npm scripts:**
- `npm run export-exchanges` — Scans ts/src/ and updates all registration files
- `npm run emitAPI {exchange}` — Generates abstract classes (all languages)
- `npm run emitAPITs` — TypeScript abstract only
- `npm run tsBuild` — TypeScript → JavaScript compilation
- `npm run transpileRest {exchange}` — TypeScript → Python/PHP for one exchange
- `npm run force-transpileRest` — Force re-transpile all exchanges
- `npm run fast-force-transpileRest` — Multi-process force transpile

## Transpilation Rules (CRITICAL)

These constraints ensure the TypeScript transpiler can correctly convert code to Python/PHP/Go/C#.

### Hard Constraints

1. **No ternary operators** — Use explicit `if/else` blocks instead of `condition ? a : b`
2. **No type annotations on local variables** — Only `const x: Dict = {}` is allowed (established pattern). Never annotate other locals.
3. **No `null` checks** — Always check against `undefined`. Never use `=== null` or `!== null`.
4. **Space before helper parentheses** — Write `this.safeString (obj, 'key')` not `this.safeString(obj, 'key')`
5. **No closures or arrow functions** — No `const fn = () => {}`, no `.map(x => ...)`, no `.filter(x => ...)`
6. **No dot notation for dict access** — Use `obj['key']` not `obj.key` for API response data
7. **No `||` or `??` for fallbacks** — Use explicit `if (x === undefined) { x = fallback; }` pattern
8. **No template literals** — Use string concatenation: `'hello ' + name` not `` `hello ${name}` ``
9. **No destructuring** — Use `const base = parts[0]` not `const [base, quote] = parts`
10. **No `for...of` loops** — Use indexed `for (let i = 0; i < arr.length; i++)` loops
11. **No `for...in` loops** — Use `Object.keys(obj)` with indexed loop
12. **No `async/await` in closures** — Only top-level async methods
13. **String values in single quotes** — Use `'value'` not `"value"`
14. **`undefined` not `null`** — Always return/check `undefined`

### Safe Method Patterns

Always use safe extraction methods instead of direct access:

```typescript
// Good
const id = this.safeString (response, 'id');
const amount = this.safeNumber (response, 'amount');
const timestamp = this.safeInteger (response, 'timestamp');
const status = this.safeString2 (response, 'status', 'state');  // try two keys

// Bad
const id = response['id'];        // could be undefined
const id = response.id;           // dot notation won't transpile
```

**Key safe methods:**
- `safeString`, `safeString2`, `safeStringN` — Extract string (with fallback keys)
- `safeStringLower`, `safeStringUpper` — Extract + case convert
- `safeNumber`, `safeNumber2` — Extract number
- `safeInteger`, `safeInteger2` — Extract integer
- `safeValue`, `safeValue2` — Extract any value
- `safeDict`, `safeList` — Extract dict/list
- `safeBool` — Extract boolean
- `safeTicker` — Normalize ticker structure
- `safeOrder` — Normalize order structure
- `safeCurrencyStructure` — Normalize currency structure
- `safeSymbol` — Resolve symbol from marketId + market
- `safeCurrencyCode` — Resolve currency code from currencyId

### Parser Method Signatures

Always accept `market: Market = undefined` as second parameter for forward compatibility:

```typescript
parseTicker (ticker: Dict, market: Market = undefined): Ticker { ... }
parseOrder (order: Dict, market: Market = undefined): Order { ... }
parseTrade (trade: Dict, market: Market = undefined): Trade { ... }
```

### sign() Method Pattern

```typescript
sign (path, api = 'public', method = 'GET', params = {}, headers = undefined, body = undefined) {
    let url = this.urls['api']['rest'] + '/' + this.implodeParams (path, params);
    const query = this.omit (params, this.extractParams (path));
    if (method === 'GET') {
        if (Object.keys (query).length) {
            url += '?' + this.urlencode (query);
        }
    } else if (method === 'POST') {
        if (Object.keys (query).length) {
            body = this.json (query);
            headers = { 'Content-Type': 'application/json' };
        }
    }
    // For authenticated exchanges, add auth headers here
    return { 'url': url, 'method': method, 'body': body, 'headers': headers };
}
```

- `this.implodeParams(path, params)` substitutes `{id}` placeholders in path
- `this.extractParams(path)` returns placeholder names to omit from query
- `this.omit(params, keys)` removes keys from params dict

### handleErrors() Method Pattern

```typescript
handleErrors (httpCode: int, reason: string, url: string, method: string, headers: Dict, body: string, response, requestHeaders, requestBody) {
    if (response === undefined) {
        return undefined;
    }
    const error = this.safeString (response, 'error');
    if (error !== undefined) {
        throw new ExchangeError (this.id + ' ' + error);
    }
    return undefined;
}
```

## Exchanges Without fetchMarkets (Swap Services)

For swap/convert services that have no predefined markets, you can skip `loadMarkets()` and parse symbols manually:

```typescript
async fetchTicker (symbol: string, params = {}): Promise<Ticker> {
    const parts = symbol.split ('/');
    const baseId = this.safeStringLower (parts, 0);
    const quoteId = this.safeStringLower (parts, 1);
    // ... use baseId/quoteId directly in API request
}
```

And derive the symbol from response data in parsers:

```typescript
parseTicker (ticker: Dict, market: Market = undefined): Ticker {
    const currencyFrom = this.safeString (ticker, 'currency_from');
    const currencyTo = this.safeString (ticker, 'currency_to');
    let symbol = undefined;
    if (currencyFrom !== undefined && currencyTo !== undefined) {
        const baseCode = this.safeCurrencyCode (currencyFrom);
        const quoteCode = this.safeCurrencyCode (currencyTo);
        symbol = baseCode + '/' + quoteCode;
    }
    // ...
}
```

## Development Workflow

1. Edit ONLY `ts/src/{exchange}.ts`
2. Type-check: `npx tsc --noEmit ts/src/{exchange}.ts` (ignore node_modules errors)
3. Build: `npm run export-exchanges && npm run emitAPI {exchange} && npm run tsBuild`
4. Transpile: `npm run transpileRest {exchange}`
5. Test: `npm run cli.ts -- {exchange} fetchTicker BTC/USDT`
6. Or test Python: `npm run cli.py -- {exchange} fetchTicker BTC/USDT`

## Common Pitfalls

- **Forgetting `this.` before methods** — `safeString()` must be `this.safeString()`
- **Using dot notation** — `response.data` must be `response['data']`
- **Using ternaries** — transpiler cannot handle them
- **Using `null`** — always use `undefined`
- **Missing space before parens** — `this.safeString(` must be `this.safeString (`
- **Arrow functions** — no lambdas, no callbacks, no closures
- **Template literals** — use `+` concatenation
- **Destructuring** — use indexed access instead
- **`for...of`/`for...in`** — use indexed for loops
- **Manually editing transpiled files** — they get overwritten on next build
